EXTENSÕES CHROME

Extensões internas desenvolvidas pela equipe para agilizar o atendimento e integração com os sistemas Betha.

Token Capture
v3.0 Manifest V3

Captura automaticamente os tokens Authorization e User-Access de qualquer sistema Betha enquanto você navega. Elimina a necessidade de abrir o DevTools para copiar tokens manualmente.

  • Intercepta requisições em todos os sistemas Betha em tempo real
  • Exibe e copia os tokens com um clique no popup
  • Persiste o último token capturado via chrome.storage
  • Funciona com qualquer módulo do cloud Betha
⬇ Baixar extensão

Instalação — modo desenvolvedor

  1. Baixe e descompacte a pasta da extensão em um local fixo no seu computador
  2. Abra o Chrome e acesse chrome://extensions
  3. Ative o Modo do desenvolvedor no canto superior direito
  4. Clique em Carregar sem compactação e selecione a pasta token-extension
  5. O ícone aparece na barra do Chrome — navegue até qualquer sistema Betha e clique para ver o token capturado
Atendimento MC Sul
v1.0 Manifest V3 Side Panel

Central de Atendimento da região Sul — Médias Contas — acessível como painel lateral do Chrome. Mantém os recursos de atendimento sempre visíveis enquanto você trabalha em outras abas.

  • Abre como painel lateral nativo do Chrome (sem popup sobreposto)
  • Recursos de atendimento sempre acessíveis sem trocar de aba
  • Focado na equipe Betha Sistemas — Região Sul

Confirmação Betha
v1.0 Manifest V3

Preenche automaticamente o campo de confirmação de exclusão nos sistemas Betha. Elimina a necessidade de copiar e colar o código manualmente.

  • Detecta automaticamente o código de confirmação na tela
  • Preenche o campo com um clique no popup
  • Compatível com os módulos do cloud Betha
